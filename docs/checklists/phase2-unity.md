# צ'קליסט בדיקה — Phase 2: ארגז חול Unity

## פתיחה ראשונה (פעם אחת)

1. התקן **Unity 6 LTS** (כל גרסת 6000.x) דרך Unity Hub.
2. ב-Unity Hub: **Add → Add project from disk** → בחר את התיקייה `unity/` שבתוך הריפו (לא את שורש הריפו).
3. פתח את הפרויקט. הפתיחה הראשונה תוריד חבילות (URP, Newtonsoft) — ייקח כמה דקות.
4. בתפריט העליון: **Tiberium Dusk → Setup Project (scene + URP)** — יוצר את הסצנה ומגדיר URP. אם ה-URP נכשל (תראה אזהרה בקונסול) — המשחק עדיין ירוץ על ה-pipeline המובנה; זה בסדר לשלב הזה.
5. ודא שהסצנה `Assets/Scenes/Main` פתוחה ולחץ **Play**.

## מה אמור לעבוד (סמן ✓)

- [ ] נטענת מפה תלת־מימדית: קרקע ירקרקת־אפורה, נהר כחול כהה חוצה באמצע, גשר (כביש) יחיד מעליו, רמה מוגבהת בדרום־מזרח עם רמפה, סלע חסום בצפון־מזרח
- [ ] 6 יחידות ענבר (שלך) בצפון, 3 יחידות ארגמן (יריב) בדרום
- [ ] קליק שמאלי על יחידה שלך — טבעת ירוקה זרחנית מופיעה מתחתיה
- [ ] גרירת מסגרת (drag) — בוחרת כמה יחידות; Shift מוסיף לבחירה
- [ ] אי אפשר לבחור יחידות של היריב (ארגמן)
- [ ] קליק ימני — היחידות נוסעות ליעד: מסתובבות קודם לכיוון, ואז נוסעות
- [ ] טנקים איטיים מחי"ר? לא — הבאגי הכי מהיר, חי"ר איטי, טנקים באמצע; על כביש כולם מהירים יותר
- [ ] פקודת תנועה לצד השני של הנהר — היחידות מתנקזות לגשר היחיד וחוצות בטור
- [ ] בחירת 3+ יחידות ותנועה יחד — נעות כקבוצה ומתפזרות סביב היעד בלי להיתקע
- [ ] יחידות לא נכנסות זו לתוך זו ולא חולקות תא
- [ ] עלייה ברמפה לרמה — הטנק מאט בעלייה; אי אפשר לטפס על הצוק ישירות
- [ ] מקש S — עצירה מיידית
- [ ] מצלמה: WASD/חצים להזזה · גלגלת לזום · לחצן אמצעי לגרירה · Q/E סיבוב 90°
- [ ] בפינה למעלה: שורת סטטוס ירוקה עם מספר טיק רץ ומספר הנבחרות

## אם משהו נשבר

- שגיאות קומפילציה בקונסול → העתק לי את השגיאה המלאה (קובץ + שורה)
- מסך ריק/ורוד → כנראה עניין URP; הרץ **Tiberium Dusk → Switch Project to URP** שוב, או ספר לי מה האזהרה
- החבילות לא נטענות → ודא שפתחת את `unity/` מתוך הריפו המלא (הסים נטען מ-`../sim`)
