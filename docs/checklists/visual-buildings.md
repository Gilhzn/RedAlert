# צ'קליסט: שדרוג ויזואלי — מבני תלת־מימד עם טקסטורות

מה השתנה: כל 30 המבנים נבנים עכשיו מ"מתכונים" (`unity/Assets/Resources/BuildingRecipes.json`)
— הרכבת קופסאות/גלילים/רמפות עם טקסטורות מתוך אטלס מצויר
(`unity/Assets/Resources/Textures/structure_atlas.png`): לבנים, פלדה, פסי אזהרה,
דלתות ענק, חלקים זוהרים. בהשראת סגנון ה־RTS הקלאסי של סוף שנות ה־90.

## בדיקה ב־Unity

1. `git pull` על הענף, פתחו את `unity/` ב־Unity 6, המתינו לייבוא.
2. אם זו פעם ראשונה: **Tiberium Dusk → Setup Project (scene + URP)**.
3. Play ▶ ואז START במסך הפתיחה.

סמנו:

- [ ] מתחם הבנייה: מבנה מתכתי + מגדל מנוף זהוב + מיכלים + רמפת אזהרה
- [ ] בית הזיקוק: מיכל ענק עם פס זוהר ירוק + ארובה + רמפה
- [ ] תחנת כוח: שני מגדלי קירור מתכתיים על גוף זהוב (דומיניון)
- [ ] מפעל נשק: האנגר לבנים עם דלת ענק, משקוף פסי אזהרה וארובות (כמו בתמונת הרפרנס!)
- [ ] מגדל שמירה: פלטפורמה על 4 רגליים
- [ ] הטקסטורות חדות (פיקסל־ארט; לא מרוחות)
- [ ] חלקים זוהרים באמת זוהרים (bloom): ירוק בזיקוק, כחול במרכז טכנולוגיה
- [ ] פס תחתון בצבע השחקן בחזית כל מבנה (זהוב לכם, ארגמן לאויב)
- [ ] אצל האויב (מסדר הנחש): מבנים שחורים/ארגמן, אובליסק עם גביש אדום זוהר
- [ ] קליק על מבנה עדיין בוחר אותו (ה־collider החדש עובד)
- [ ] FPS תקין עם בסיס מלא (המבנים הם mesh אחד + חלקי זוהר)

## אם משהו שבור

- מבנה נראה כקופסה אפורה פשוטה → אין לו מתכון או ש־`BuildingRecipes.json`
  לא נטען; בדקו ב־Console שגיאת JSON.
- טקסטורות מרוחות/מטושטשות → ה־atlas לא נטען כ־Point; ודאו שהקובץ
  `Resources/Textures/structure_atlas.png` קיים ויובא.
- הכל ורוד → בעיית שיידר URP; הריצו שוב Setup Project.

## חידוש הנכסים (אופציונלי, לא נדרש)

```bash
python3 tools/gen_structure_atlas.py .      # מחולל את האטלס מחדש
python3 tools/gen_building_recipes.py .     # מחולל את קובץ המתכונים
python3 tools/render_building_previews.py   # תצוגה מקדימה ב-tools/building_previews.png
```
