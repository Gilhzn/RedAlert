# צ'קליסט בדיקה — Phase 4: קרב

(הרץ שוב **Tiberium Dusk → Create Main Scene Only** לפני הבדיקה — נוסף רכיב אפקטים לסצנה.)

## מה חדש במפה
לאויב (ארגמן) יש עכשיו בסיס קטן ליד השדה הכחול: תחנת כוח + **מגדל שמירה** שיורה. לך נוסף **מהנדס** (קפסולה קטנה ליד הכוח שלך).

## סמן ✓

### תקיפה
- [ ] קליק ימני על אויב עם טנקים נבחרים — סמן תקיפה: הטנקים רודפים, נעצרים בטווח, הצריח מסתובב לעבר המטרה, ויורים פגזים (כדורים זוהרים עפים!)
- [ ] פיצוץ כתום מתרחב כשפגז פוגע וכשיחידה מתה; מבנה שנהרס = פיצוץ גדול
- [ ] פסי חיים ירוק→צהוב→אדום מופיעים מעל יחידות פגועות
- [ ] רובאים כמעט לא שורטים טנק (שריון כבד מול נשק קל — טבלת Verses), אבל טורפים חי"ר
- [ ] **A + קליק ימני** על הקרקע = Attack-Move: היחידות מתקדמות, עוצרות להרוג כל אויב בדרך, וממשיכות ליעד
- [ ] יחידה עומדת תוקפת לבד אויב שנכנס לטווח הראייה שלה

### מגדל השמירה של האויב
- [ ] חייל בודד שנשלח לבסיס האויב נקטל ע"י המגדל
- [ ] המגדל מסתובב לעבר מטרות; כוח טנקים משמיד אותו

### מהנדס
- [ ] קליק ימני עם המהנדס על מבנה אויב — הוא רץ אליו, נעלם, **והמבנה עובר אליך** (צבע הגג מתחלף לענבר) עם חיים מלאים

### דריסה
- [ ] טנק שנוסע דרך חי"ר אויב פשוט דורס אותו (חי"ר שלך לא נדרס על ידך)

### ותק
- [ ] יחידה שהורגת הרבה מקבלת דרגה ופוגעת חזק יותר (קשה לראות ויזואלית עדיין — סימון דרגות יגיע בהמשך)
