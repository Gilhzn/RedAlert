# צ'קליסט בדיקה — Phase 7: המשחק הראשון! סקירמיש נגד AI

(הרץ **Tiberium Dusk → Create Main Scene Only** מחדש.)

## זה כבר משחק אמיתי
אתה (דומיניון, ענבר) מול **AI מסדר הנחש** (ארגמן) שמתחיל כמוך מ-MCV על הרמה בדרום־מזרח — הוא יפרוס בסיס, יבנה כלכלה וצבא, **ויתקוף אותך בגלים**.

## סמן ✓

### ערפל קרב
- [ ] המפה מתחילה שחורה מלבד סביבתך; יחידות שנעות חושפות אותה לתמיד
- [ ] אזור שנחשף אך אין בו יחידות שלך — מוחשך קלות, ויחידות אויב בו נעלמות
- [ ] שדות קריסטל לא נראים עד שמגלים אותם

### רדאר ומיני־מפה
- [ ] בפינה השמאלית־תחתונה: **רעש סטטי** כל עוד אין לך מכ"ם (או שאין חשמל)
- [ ] אחרי בניית כיפת מכ"ם: מפת שטח + נקודות יחידות בצבעי שחקנים + שרוד
- [ ] קליק על המיני־מפה מקפיץ את המצלמה לשם

### ה-AI
- [ ] תוך ~2 דקות מהתחלה: גלוש לכיוון הרמה (או שלח סייר) — האויב פרס בסיס: מבנים קמים, קציר עובד
- [ ] אחרי כמה דקות מגיע **גל תקיפה** ראשון לבסיסך — עם עוד גלים אחריו
- [ ] אם תהרוס את כל מה שיש לו: מסך **MISSION ACCOMPLISHED** ירוק + הריפליי נשמר; אם הוא ימחק אותך: **MISSION FAILED**

### ריפליי
- [ ] בסוף משחק מוצג נתיב קובץ `replay_*.rdt` שנשמר
