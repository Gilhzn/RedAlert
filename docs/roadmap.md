# Roadmap — 10 שלבים / 10 Phases

כל שלב מסתיים ב: `dotnet test` ירוק, קומיט+פוש, ו(בשלבים ויזואליים) צ'קליסט בדיקה למשתמש ב-Unity.
Each phase ends with: green `dotnet test`, commit+push, and (visual phases) a user checklist for Unity.

| # | שלב | תוצר מרכזי | בדיקת סיום |
|---|------|------------|------------|
| 0 | יסודות | ריפו, מסמכים, שלד sim+tests, סכימות JSON, CI | CI ירוק |
| 1 | ליבת סימולציה | fixed-point, גריד+גבהים, טיקים, Orders, RNG, hash, A*, flow fields | אותו זרע ⇒ אותו hash אחרי 10k טיקים |
| 2 | Unity ראשוני | מפה תלת־מימדית, מצלמה, בחירה, תנועה, אינטרפולציה | המשתמש מזיז יחידות במפה |
| 3 | כלכלה ובנייה | טיבריום/קציר/זיקוק, חשמל, תורי בנייה, מיקום, MCV, סרגל צד | בסיס עובד + מבחני כלכלה |
| 4 | קרב | נשקים/ראשי נפץ, פרויקטילים, הגנות, ותק, EMP, מהנדסים | קרב AI-vs-AI דטרמיניסטי |
| 5 | צבאות מלאים | כל היחידות/מבנים/עצי טק, הנעות מיוחדות, מטוסים, מודלים | שני עצי טק נבנים במלואם |
| 6 | סופר־נשקים | Ion/Missiles/Firestorm/Hunter-Seeker, הסוואה, סופות יונים, ארגזים | מבחני sim לכל מערכת |

## עקרונות חוצי־שלבים

1. שום לוגיקת משחק ב-Unity — הכל בסים הנבדק.
2. כל ערך משחקי ב-`data/*.json`, שמות תצוגה רק ב-locale.
3. אין נכסי EA בריפו; `reference/` הוא מקומי בלבד וב-.gitignore.
4. כל שינוי איזון מהמקור מתועד ב-`docs/balance-changes.md`.
