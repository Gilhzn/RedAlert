TIBERIUM DUSK

תצוגה מקדימה אינטראקטיבית בדפדפן: סקירמיש מוקטן נגד מסדר הנחש, עם נתוני היחידות האמיתיים מקובצי המשחק. קצרו ורידיום, בנו בסיס, הדפו גלים — והשמידו את בסיס האויב.

זו הדגמת JavaScript — לא בניית ה־Unity WebGL המלאה. את המשחק המלא בונים ב־Unity Editor דרך התפריט Tiberium Dusk ← Build ← WebGL.

  • קליק ימני — תנועה / תקיפה
  • WASD / חיצים / גרירת אמצע — הזזת מצלמה, גלגלת — זום
  • סרגל צד — בנייה (מבנים ממוקמים בקליק על המפה); ▶ ממזער אותו
  • מובייל — הקשה: בחירה/פקודה, לחיצה ארוכה+גרירה: בחירת קבוצה, גרירה: מצלמה, צביטה: זום
